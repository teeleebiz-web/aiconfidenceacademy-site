# ACA lesson delivery requirements

Follow the established publication protocol in `academy/AGENTS.md`.

## Required lesson and workbook association

Terrence explicitly reaffirmed this requirement on October 10, 2026 after missing workbook entry buttons in Lessons 3.2 and 3.3.

- Every curriculum lesson must include its associated workbook section. The workbook is a required deliverable, never optional or deferred.
- Before calling a lesson ready, verify BOTH the matching workbook content and the actual lesson-to-workbook connection. A database row, standalone workbook test or production ZIP is insufficient evidence of accessibility.
- Check that the lesson displays its workbook entry, opens the correct journey and lesson section, retains earlier workbook answers, supports Print / Save PDF and returns to the originating lesson. Keep unreleased sections locked.
- Cover the protected review entry in regression tests; do not maintain a separate lesson-number allowlist that silently hides workbooks for later journeys.
- Check the intended signed-in route when available. If signed-in acceptance remains unavailable, report that limitation plainly; do not claim a live signed-in click-through was verified.
- Preserve approved teaching, media, previous workbook pages and learner work while correcting an association failure. Take time to scrutinize the complete delivery path before reporting completion.
