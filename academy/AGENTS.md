# ACA lesson publication workflow

Follow the user's current authorization. Limit every edit to the named lesson or
explicitly approved shared change. A progress comment is not a reason to stop
authorized work.

## One approved lesson, one destination

- Before editing, bind the requested lesson number to its existing course ID,
  journey ID, lesson ID, and website route. Match the approved media to its exact
  storage object; do not select a different version from a similar title.
- Update that existing lesson record. Do not create another welcome, preview,
  lesson, or website entry for the same approved material.
- Journey Three starts at lesson 3.1. `/academy/phase-one/?journey=3` opens
  `/academy/phase-one/?lesson=3.1`. A separate Journey Three introduction is
  obsolete and must not be recreated or reattached.
- Current approved website records and the user's current instructions govern
  publication. Historical exports and publication records must not override them.

## Preview, approval, publication

- Label review artifacts with the lesson number, PREVIEW, and a version, for
  example `ACA_3.2_PREVIEW_v01`. Keep preview labels and working commentary out of
  learner-facing curriculum. Use the established website design for review.
- Record which exact version the user approved. After approval, replace the
  designated placeholder at the existing lesson destination in the same task.
- Retire the obsolete entry and its navigation as part of replacement. Preserve
  media referenced by the approved lesson. Do not delete shared storage objects.
- Check the direct lesson address, curriculum navigation, any old entry address,
  intended media, and workbook destination. Add a focused regression check when
  changing entry routes so obsolete pages cannot return unnoticed.
- Review the exact diff and database row count. Verify the authorized fields
  changed and retained lesson content did not. Publish only the checked change.
- Report completion with the official lesson link and honest verification limits.
  Do not claim browser playback was verified when only deployment/data were checked.

## Design continuity

Keep the established navy/gold design, player controls, and curriculum content.
Video lessons do not introduce a script-reading disclosure. Audio lessons retain
their script-reading option. The approved workbook placement standard is directly
above Guided practice. Apply pending placement changes only within user-authorized
scope; recording this standard does not authorize an unrelated site-wide edit.
